🚀 GitHub 推播與免費網站發布 SOP

Antigravity 代理 AI 教學實踐：從帳號開立、倉庫建立、Token 金鑰保護到網頁全自動發布完整流程指引

1

步驟一：免費註冊 GitHub 帳號與個人網址規劃

GitHub 是全球最大程式碼託管平台，同時提供終身免費的靜態網頁託管 (GitHub Pages)，老師完全不需要花錢購買網址或租用主機！

  1. 打開瀏覽器連至 https://github.com，點擊右上角綠色 Sign up 按鈕。
  2. 輸入您的電子郵件（如學校信箱或常用 Gmail，用於接收確認信）。
  3. 設定一組高強度密碼。
  4. 決定使用者名稱 (Username)：
    ⭐ 命名關鍵叮嚀：此帳號名稱將會直接成為您的「個人教學網址」！
    例如：簡老師註冊之帳號為 stjedu，未來發布的網站網址就會自動固定為：
    👉 https://stjedu.github.io/【倉庫名稱】/
  5. 完成拼圖防偽驗證，收信填寫 8 位數驗證碼啟用。
2

步驟二：在 GitHub 上建立專屬倉庫 (Repository)

倉庫就像是雲端上的專屬資料夾，用來存放我們的 index.html 網頁、電路圖檔與投影片。

  1. 登入 GitHub 後，點擊網頁右上角「+」號 ➔ 點選 「New repository」。
  2. Repository name（儲存庫名稱）：輸入簡潔英文字母，本次實務輸入為 www。
  3. 權限設定：務必勾選 Public（公開）（這樣 GitHub Pages 才能免費開放學生與大眾瀏覽）。
  4. 其餘選項（README、.gitignore）保持空白預設免打勾。
  5. 點擊最下方綠色按鈕 「Create repository」。
  6. 完成後取得倉庫專屬網址：https://github.com/stjedu/www。
3

步驟三：產生個人存取金鑰 (Personal Access Token)

為了資訊安全，GitHub 全面禁止使用傳統登入密碼從本機推送檔案，必須使用一組專屬的 Personal Access Token (權杖) 作為安全身分憑證。

  1. 在瀏覽器打開金鑰設定頁面：https://github.com/settings/tokens
  2. 點擊右上角 「Generate new token」 ➔ 選擇 「Generate new token (classic)」。
  3. Note（備忘名稱）：輸入 antigravity。
  4. Expiration（有效期限）：建議選擇 No expiration（無期限）或 30 天。
  5. Select scopes（勾選權限）：
    🔒 權限關鍵勾選：請務必將第一個 repo（包含底下所有子項目）完整打勾！這樣代理人才能擁有上傳檔案至儲存庫的權限。
  6. 滑至最底端，點擊綠色 「Generate token」 按鈕。
  7. 複製金鑰代碼：畫面會顯示一串以 ghp_ 開頭的長代碼（此代碼僅顯示一次，請妥善保管勿外流）。
# 個人金鑰 (安全保護示範)：
token = "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" (金鑰已做馬賽克遮罩處理)
4

步驟四：下達大師級提示語，交由 AI 代理人全自動推播

老師完全不需要在黑底白字命令列敲複雜的 Git 指令！只要把您的倉庫網址與金鑰複製給 Antigravity，代理人就會在背景自主完成打包、設定與推送：

📜 大師級實戰提示語範本（可直接反白複製使用）：
「我已經在 GitHub 上建立好我的公開倉庫，網址是 https://github.com/stjedu/www，
我的個人金鑰 Token 是 ghp_【貼上您的金鑰】。
請扮演我的教學自動化工程師，幫我執行以下連續動作鏈：
1. 將本地端的 index.html、電路圖檔與 23 頁研習簡報自動進行 Git 初始化並 Commit。
2. 使用我的 Token 身分，將所有檔案強制推送到倉庫的 main 分支。
3. 透過 GitHub API 自動為我開啟 GitHub Pages 靜態網站功能。
4. 檢測上線狀態，並回報我最終的公開網站網址！」

🤖 代理人在背景自主執行的背後動作鏈：

$ git init
$ git config user.name "stjedu"
$ git add index.html circuits/ *.pptx
$ git commit -m "feat: adopt portal framework"
$ git push https://stjedu:ghp_***@github.com/stjedu/www.git main [狀態：200 OK 成功推播]
$ curl -X POST https://api.github.com/repos/stjedu/www/pages [狀態：201 Created 成功啟用 Pages]
5

步驟五：成果驗收與全世界公開上線 LIVE

推送完成後約 30 秒至 1 分鐘，GitHub 就會自動完成伺服器部署！

🎉 簡老師專屬站點正式生效！
公開瀏覽網址：👉 https://stjedu.github.io/www/
專案原始碼：👉 https://github.com/stjedu/www
